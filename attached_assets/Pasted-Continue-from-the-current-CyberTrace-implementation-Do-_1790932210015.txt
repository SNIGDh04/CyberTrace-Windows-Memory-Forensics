## PHASE 4 — Correlation Validation

Review every correlation rule.

Only create a relationship when there is an explicit evidence-backed basis.

Examples:

PARENT_CHILD:
child.PPID == parent.PID

CONNECTS_TO:
network PID == process PID

LOADS_DLL:
DLL PID == process PID

EXECUTED_WITH:
command PID == process PID

Do not create relationships merely because two artifacts look suspicious.

Store for every relationship:

* relationship ID
* source evidence ID
* target evidence ID
* relationship type
* deterministic reason
* source fields used
* confidence/evidence level

## PHASE 6 — Hypothesis Engine Review

The hypothesis engine must be evidence-driven.

Use language such as:

* "Possible sequence"
* "Observed evidence indicates..."
* "This relationship may suggest..."
* "Requires analyst validation"

Never say:

* "Confirmed attack"
* "Confirmed malware"
* "Attacker definitely did X"

unless the underlying evidence actually establishes that fact.
